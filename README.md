Дипломный проект - веб-сайт бренда "Силант".
ТЗ тут дублировать не буду. Думаю тот, кто будет это проверять, видел его over 9000 раз.

Установка:
1. клонируем репозиторий
2. переходим в корень
3. с запущенным Docker'ом выполняем там `docker-compose up --build`
4. ждёмс чут-чут
5. PROFIT

Сайт: `http://localhost:5173/`
Админка Django: `http://localhost/8000/admin/`

БД уже будет наполнена тестовыми данными для проверки (те что были в эксельке).

Аккаунты для тестов (созданы на основе тех же данных из эесельки):
1. Клиент: логин - client-login-4 / пароль - cl-temp-password-4
2. Сервисная организация: логин - serv-comp-login-12 / пароль - sc-temp-password-12
3. суперадмин (тот же менеджер - у них одинаковые права доступа, только менеджеры не могут в админку Django): логин - godadmin / пароль - lordjesus

Документации по API нету. Весь сайт и так через DRF апишку и работает.

Enjoy. =)
